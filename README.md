# Movie Explorer (Frontend Assignment)
A simple React application for exploring movies from a mock JSON API (movies.json)
The app allows users to first log in (the first page they land on), if they do not have an account they are able to register. The Login and Register pages are the public routes. 
Authenticated users are able to browse movies, filter by genre, view movie details, and simulate a search experience. The can log out and it will redirect them back to login page.

## Project Overview
Movie Explorer demonstrates core frontend concepts:
- React components
- React Router for navigation
- Fetching mock data
- Conditional rendering (loading, empty results)
- Basic state management with hooks (`useState`, `useEffect`, `useRef`)
